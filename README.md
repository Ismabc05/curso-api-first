# 🚀 Proyecto Final – Curso API First (Platzi)

Este repositorio contiene el proyecto final desarrollado como parte del **Curso de API First de Platzi**, donde se aplicaron los principios de diseño centrado en la API antes de la implementación.

---

## 📌 Descripción

El proyecto consiste en el diseño e implementación de una API siguiendo la metodología **API First**, priorizando la definición del contrato como base del desarrollo.

Se utilizó **OpenAPI (Swagger)** para especificar la API antes de su construcción, asegurando claridad, consistencia y facilidad de integración.

---

## 🎯 Objetivos del curso

Durante este proyecto se aplicaron los siguientes conceptos:

- Diseño de APIs siguiendo enfoque API First
- Definición de contratos con OpenAPI 3.0
- Implementación de endpoints REST
- Documentación de la API
- Buenas prácticas de diseño de APIs
- Separación entre contrato e implementación

---

## 🧠 Enfoque API First

El enfoque API First implica:

- Diseñar la API antes de escribir código
- Usar el contrato como fuente de verdad
- Facilitar el desarrollo paralelo entre equipos
- Reducir errores de integración
- Mejorar la escalabilidad del sistema

---

## 🛠️ Tecnologías utilizadas

- Node.js
- Express / FastAPI
- OpenAPI 3.0 (Swagger)
- Postman para pruebas
- Docker (opcional)
